# User Flows

## Route map
- `/` (default hash-empty): Main transient-shaper UI.
- `#/explainer`: Cinematic explainer mode.

## Primary user journeys
1. Initialize engine → load file → play → tweak bands/globals → export.
2. Compare settings using A/B switch and copy.
3. Load preset and adapt with linked multiband attack/sustain edits.
4. Open explainer to understand transient shaping concepts.

## Edge-case journeys
- User toggles solo across multiple bands then unsolos all.
- User edits while playback active.
- User runs without SAB support (degraded visualization path).
